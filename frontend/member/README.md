# GMCA Member Frontend

This folder contains a starter frontend for the GMCA member portal, including:

- login page
- dashboard
- profile page
- events page
- event details page

## Structure

- css/: shared styles and page-specific styles
- js/: configuration, API helpers, authentication, and page scripts
- components/: reusable HTML partials

## Notes

The pages are wired to call the backend API at `http://localhost:5000/api` by default.
